# Quickstart

## Create a configuration

1. Go to `Dynamic Search -> Search Configurations`.
2. Create a new record.
3. Choose the target model.

## Add filters

- Domain filter example: `[('state', '=', 'draft')]`
- Boolean filter: choose a boolean field and type `Boolean`
- Date filter: choose a date or datetime field and a predefined period

## Add group by entries

- Standard grouping: choose any supported stored field
- Date grouping: choose a date or datetime field and set `Day`, `Week`, `Month`, `Quarter`, or `Year`

## Apply changes

1. Run the validator.
2. Fix any reported errors.
3. Click `Apply & Reload Views`.
